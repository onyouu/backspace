# 오류 수정 이어서 진행한 내용

2026년 10월 7일, 실행 중인 작업과 저장된 오류 기록을 확인했습니다. 자료를 다시 업로드하거나 저장된 이해 노트를 지우지 않았습니다. 확인과 테스트를 위해 새로운 NVIDIA·Jev 분석 요청을 보내지도 않았습니다. 사용자가 이미 시작한 분석은 계속 실행 중입니다.

**이전 실패 때문에 재개가 바로 막히던 문제를 고쳤습니다.** 아주 작은 자료 구간이 한 번 시간 초과하면, 다음 실행에서도 이전 실패 기록만 읽고 끝나는 경우가 있었습니다. 이제 사용자가 재개하면 그 작은 구간을 한 번 다시 시도할 수 있습니다. 이미 완료한 결과는 그대로 재사용하며, 큰 구간을 다시 보내는 반복 호출은 추가하지 않았습니다.

**강조 인용의 목록 형식을 제한적으로 복구합니다.** 오류 기록에는 `explicit_emphasis` 목록 안의 항목이 규격과 다르다고 남아 있습니다. 당시 실제 응답 내용은 기록되지 않아 정확히 어떤 값이었는지는 확인할 수 없습니다. 지금부터 빈 값은 빈 목록으로, `quote` 하나만 가진 항목은 그 인용문 그대로 처리합니다. 숫자나 다른 형태의 잘못된 항목은 여전히 오류로 남깁니다. 원문에 없는 인용문을 만드는 방식으로 해결하지 않았으며, 원문 일치·명시적 강조 검사는 계속 실행합니다.

**응답이 조금씩 들어오며 대기가 늘어나는 문제를 줄였습니다.** 기존에는 각 통신 대기에 시간 제한이 있어도 전체 응답을 받는 시간이 길어질 수 있었습니다. 이제 연결 대기와 응답 읽기가 같은 시간 예산을 사용합니다. 제한 시간을 늘리지 않았습니다. PC 절전이나 인터넷 장애 자체를 해결한 것은 아니며, 그런 경우의 실패 기록은 남겨 재개할 수 있게 합니다.

**읽기 완료 안내를 분석 완료와 구분했습니다.** 예전 그래프 오류가 남아 있어도 이번 자료 읽기가 끝났으면 ‘텍스트·이미지 읽기 완료’로 표시합니다. 일부 파일만 읽지 못했으면 완료한 파일은 보존합니다. 읽기 재시도 버튼은 읽기만 실행하고 새 LLM 분석을 시작하지 않습니다. 화면을 닫거나 새로고침해서 연결이 끊겼을 때 불필요한 서버 오류를 반복 출력하는 문제도 수정했습니다.

회귀 테스트 186개와 화면 코드 검증이 통과했습니다. 추가로 연결 대기가 전체 시간 예산에 포함되는 경우와 파일 하나의 읽기 실패가 다른 파일의 성공을 가리지 않는 경우도 검증했습니다. 테스트는 임시 작업공간과 모의 응답을 사용합니다.

19:00 확인 시점에는 실제 이해 노트 116개가 저장돼 있었고, 교사 자료 10개 중 일부는 아직 이해 또는 그래프 분석이 미완료였습니다. 이 수치는 진행 중인 작업의 한 시점이며 전체 분석 완료를 뜻하지 않습니다.

**적용 시점:** 화면 수정은 새로고침하면 적용됩니다. 실행 중인 분석을 끊지 않기 위해 서버를 재시작하지 않았으므로 Python 서버 수정은 다음 서버 실행부터 적용됩니다. 이번 테스트 통과가 현재 작업의 모든 API 오류가 해결됐다는 뜻은 아닙니다.
