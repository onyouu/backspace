# Backspace Learning Studio · Black & Lime

학생이 입력하는 자료는 두 단계로 분리한다.

1. **선생님 자료:** 과거 PPT·학습지·시험지로 누적 자료 그래프, 문항별 사고 그래프, 반복 패턴과 Teacher Model을 생성한다.
2. **이번 시험범위:** 이번 시험에 공부할 학습자료를 별도 dataset으로 분석한다. Teacher Model과 비교하여 중요도·학습 깊이·활동·일정을 만든다.

이번 시험범위 자료는 선생님 분석용 dataset에 자동 합쳐지지 않는다. 생성한 계획의 입력 해시도 별도 시험범위 dataset을 가리킨다. 초기에는 학생 성취·약점·망각을 미관찰로 유지한다.

## 실행

프로젝트 루트에서 Python 3.11 이상과 npm을 사용한다.

```powershell
python -m pip install -e .
npm install
python -m backspace_mvp.web --port 8766
```

브라우저에서 [Teacher Studio](http://127.0.0.1:8766)를 연다. 서버 종료는 실행 터미널에서 Ctrl+C. 포트가 사용 중이면 `--port 8767`처럼 바꿀 수 있다. GSAP은 `package-lock.json`으로 고정한 3.15.0을 로컬에서 제공하며, 브라우저가 외부 CDN이나 API를 직접 호출하지 않는다.

## 화면의 흐름

- **작업 홈:** 자료 → 사고 지도 → 계획의 짧은 연결 연출, 현재 상태와 다음 행동, 학습계획 진행 기록.
- **선생님 자료:** 과거 학습자료와 시험지 업로드. 시험지는 이름을 입력해 구분한다. Teacher Model 생성은 기존 Python 파이프라인을 실행한다.
- **Teacher Model:** 최대 24개 주변 노드를 보여주는 사고 지도와 전체 검색, 개념 연결·문항별 요구 사고·반복 패턴 전환. 잠정 가설의 지지 근거·반례 검색 범위·대안 설명, 사고 패턴, 점수와 미점수화 항목을 확인하고 JSON으로 내려받는다.
- **이번 시험범위:** 새 학습자료를 업로드해 별도의 범위 개념 지도를 만든다.
- **나의 학습계획:** 기간·하루 시간·시험 형식·계획할 개념 수를 정한다. 기본은 API 없는 템플릿 계획이며, AI 재설계를 선택하면 Jev 중요도 판단과 NVIDIA 활동 생성을 실행한다. 완료 체크·메모·버전 이력은 로컬에 저장한다.

업로드는 PDF/PPTX/PNG/JPG/TXT/MD/구조화 JSON, 각 100MiB(화면 표기 100MB)까지 지원한다. 「자료 읽기」로 로컬 PaddleOCR를 실행하고 「원문 검토」에서 불확실한 영역을 수정할 수 있다. 원본과 전사 결과는 의미 분석 전에 별도로 저장한다. [OCR 실행 및 검증 범위](perception.md)를 참고한다. 정답·해설의 명시적인 문항별 mapping 업로드 UI는 기존 CLI의 `--answer-key`를 사용한다. 문서 이름은 원래 이름으로 보존한다.

무료 구조 집계는 구조화 JSON 또는 이미 분석된 자료에 사용한다. 원문 개념 추출·Teacher Model 생성은 NVIDIA/TypeSafe에 텍스트를 전송한다. 키는 서버의 `.env`에서만 읽으며 브라우저로 보내지 않는다. 예시 열람·진행 기록·템플릿 계획은 API를 호출하지 않는다.

## 저장

```text
state/web/
  workspace/
    uploads/             입력 원문 보존
    files.json           업로드 목록과 처리 상태
    teacher/             과거 자료·시험지 분석
      dataset.json
      material_graph.json
      question_graphs/
      patterns.json
      teacher_hypotheses.json
      teacher_scores.json
      teacher_model.json
    scope/               이번 시험범위 전용
      dataset.json
      material_graph.json
    current_plan.json
    plan_history/
  demo/                  내 자료와 분리된 합성 예시
  jobs/                  실제 처리 단계와 작업 상태
```

예시 화면은 기존 통합 검증 결과가 있으면 그 복사본을 사용한다. 별도 범위 입력에 동일 합성 학습자료를 다시 입력해 분리 흐름을 보여주고 템플릿 계획을 생성한다. 이는 다른 단원으로의 전이 정확도 평가가 아니다. 통합 결과가 없는 새 설치에서는 합성 자료·문항 지도를 먼저 표시하며, Teacher Model은 실제 분석 후 생성할 수 있다. `sources/` 및 기존 검증 파일은 수정하지 않는다.

작업은 백그라운드에서 하나씩 실행하고 실제 완료된 단계만 표시한다. 실패 시 완료된 단계와 기존 최종 결과를 보존한다. 서버가 종료된 작업은 중단으로 기록하고 자동 재호출하지 않는다. 자료 변경으로 모델·계획이 오래되면 화면에 갱신 필요를 표시한다.

## 상한과 현재 한계

교사 가설 입력은 최대 12문항·4패턴·4자료 항목, 생성 가설은 2개, 교사 중요도 판단은 4개 개념부터 시작한다. 미점수화 항목은 0으로 채우지 않는다. 계획할 개념 수는 1~24개로 조절하며 포함하지 않은 개념 수와 미배정 시간을 표시한다. 큰 범위가 문맥 상한을 넘으면 기존 계획을 유지하고 대상 개념 수를 줄이도록 안내한다.

생성 입력에는 중복 점수표를 제거한 교사 문맥과 제한된 원문 인용을 사용한다. 인용 선택·누락 수와 입력 버전을 기록하며 저장된 계획에는 전체 교사 문맥·원 점수가 남는다. 이전 계획은 읽을 수 있으며 새 생성 시 문맥 버전이 달라지면 갱신한다.

개념 지도는 선택한 개념 주변 최대 24개 노드를 표시하고 전체 검색·목록에서 다른 개념으로 이동한다. 작은 화면에서는 지도 영역만 좌우로 스크롤한다. 저장된 연결만 그리며 반복 노드와 경로를 구분한다. 전체 데이터는 저장된 모델에 남으며 시각화 범위가 모델의 전체 근거 범위를 의미하지 않는다. API 판단은 과학 정답이나 교사의 사적 의도 보증이 아니며, 실제 교사 자료 정확도 평가와 사람 검수는 별도로 필요하다.

현재 서버는 **단일 사용자 로컬 프로토타입**이다. 127.0.0.1에만 연결하고 임의 파일 접근·다른 Origin의 변경 요청을 거부한다. 인터넷 공개 배포용 인증·다중 사용자·운영 인프라는 이번 구현 범위에 포함하지 않았다.

## 확인한 내용

기존 Python 테스트 81개 통과. 정적 파일 검증에 GSAP 5개 파일, 로컬 폰트·라이선스, 화면 모듈을 추가했다. `npm run check`는 모든 화면 모듈 구문과 지도 표시 범위·선택 개념·관계 보존을 검사한다. 새 웹 테스트는 자료 분리·중복 업로드·원문 무료 분석의 외부 호출 차단·Teacher Model/범위/계획 연결·완료 저장·키 가림·내려받을 모델 해시·정적 파일/Origin 제한을 확인한다. 기존 v0.1~v0.7 계약 테스트도 유지했다.

실제 브라우저에서 가설 근거 모달, 문항 선택, 계획 완료/취소 저장, 데스크톱과 모바일 레이아웃을 확인했다. 이 웹 구현·검증에서는 NVIDIA/Jev를 추가 호출하지 않았다. 이전 실제 API 결과 열람과 모의 응답 테스트를 이용했다.

## 디자인과 모션

차콜/크림/라임 토큰은 `web_static/style.css`에서 관리한다. 한국어 Pretendard Variable과 영문 Space Grotesk은 로컬 WOFF2로 제공하며 `web_static/fonts/`에 각 SIL OFL 라이선스를 포함했다. 브랜드 SVG와 홈 연결 그래픽은 코드로 제작했다.

화면 구성 `views.js`, 저장된 그래프 탐색 `graph.js`, 원문 검토 `perception.js`, 선택적 모션 `motion.js`, API·탐색·상태 연결 `app.js`로 나눴다. 서버 데이터 갱신은 해당 목록·계획·보고 영역만 바꾸며 입력 중인 설정·메모와 스크롤, 선택 개념을 보존한다. 원문 검토의 필터·페이지 전환도 미저장 글자를 유지하며, 닫기/다른 화면 이동 시 별도 확인창을 사용한다. 저장 오류는 입력을 지우지 않는다.

첫 홈 연출은 브라우저 세션당 한 번, 1.2초 내로 마친다. SplitText는 제목만 분리하며 `autoSplit`/`onSplit`으로 폰트 및 화면 폭 변화에 대응한다. ScrollTrigger는 한 번 등장하는 짧은 효과만 사용한다. Core·Flip·ScrollTrigger·SplitText·DrawSVG는 선택적 효과이며 로딩에 실패해도 자료·지도·계획 기능이 동작한다. 모션은 사용 안내에서 끌 수 있고 시스템 동작 줄이기를 우선한다. 서버 작업 완료나 진행률을 애니메이션으로 추정하지 않는다.

새 디자인 미리보기는 기존 서버를 유지한 채 별도 포트로 실행한다:

```powershell
./.venv-ocr/Scripts/python.exe -m backspace_mvp.web --port 8770
npm run check
./.venv-ocr/Scripts/python.exe -m unittest discover -s tests -v
```

[새 디자인](http://127.0.0.1:8770) · [디자인 검증 기록](design_validation.md). 기존 해시 주소와 업로드 100MiB 제한, 원본·최초 전사·수정 이력, 두 자료 공간의 분리를 유지한다.
