# 프로그램 변경 이력

상단의 **변경 이력** 버튼을 누르면 초기 개발부터 현재까지 날짜·시간 순으로 볼 수 있습니다. 제목 표시줄을 드래그해서 창을 옮기고, 닫기 또는 Escape로 숨깁니다. 제목 표시줄에 키보드 포커스를 두고 방향키로 옮길 수도 있습니다. 처음·최신 버튼은 연표 안에서 이동하며, 분석 작업과 독립적으로 동작합니다.

연표의 초기 복원 내용을 사용자 제공 개발 회고로 교체했습니다. 2026년 4월부터 10월 7일까지의 52개 사건을 아이디어·설계·구현·검증·실패·구조 전환·제품 방향·조사로 구분합니다. 구현/검증은 당시 대화에서 보고된 상태이며, 이번에 다시 실행해 확인한 결과를 뜻하지 않습니다. 손글씨 OCR은 설계/선택 단계로 표시합니다.

월만 기록된 날짜, 날짜만 있는 사건, 오전/오후·14시대·14~15시는 제공된 정밀도 그대로 보여줍니다. 정렬용 내부 기준 시각을 실제 사건 시각으로 표시하지 않습니다. 기존의 실제 코드 변경 기록은 함께 보존하고, 문서 생성 시각 기반의 옛 복원 기록은 `docs/development_timeline_previous.json`에 별도 보관했습니다. 제공한 원문은 `docs/backspace_development_history_supplied.md`에 그대로 보존했습니다.

상태·출처로 필터링할 수 있고 각 사건의 **당시 내용 보기**에서 원문 상세를 펼칩니다. 실제 코드 기록은 **변경 파일**에서 파일별 수정 시각을 확인합니다. 기록 내용은 학생 자료 상태·Teacher Model의 현재 분석 결과와 독립적입니다.

공개 연표는 `backspace_mvp/web_static/change-history.json`, 코드 비교용 해시는 `state/development_history/code_snapshot.json`에 저장합니다. API 키·학생 자료·분석 로그는 수집하지 않습니다. 이 기능은 NVIDIA/Jev를 호출하지 않습니다.

다음 코드 변경 뒤에는 프로젝트 폴더에서 실행합니다.

```powershell
# 사람이 읽기 쉬운 내용으로 기록
.\.venv-ocr\Scripts\python.exe -m scripts.update_change_history --title "변경 제목" --summary "사용자에게 달라진 점"

# 배경과 이전/이후, 결과, 다음 단계를 함께 기록
.\.venv-ocr\Scripts\python.exe -m scripts.update_change_history --title "변경 제목" --summary "무엇을 바꿨는가" --type IMPLEMENTED --module Perception --why "변경 이유" --before "이전 구조" --after "변경 구조" --result "검증 결과" --next "남은 문제"

# 설명을 아직 작성하지 않은 변경 파일을 감지해 기록
.\.venv-ocr\Scripts\python.exe -m scripts.update_change_history --scan
```

이 명령은 이전 코드 해시와 비교해 수정·추가·삭제 파일을 기록합니다. 변경이 없으면 자동 감지 항목을 중복 추가하지 않습니다. 과거 생성 시각을 매번 다시 계산하지 않으며, 최초 복원 이후의 연표를 유지합니다. 상주 감시 기능은 아니므로 다음 변경을 반영할 때 이 명령을 실행해야 합니다. 브라우저에서 갱신된 기록은 새로고침 후 확인합니다.

## 화면 확인

사용자 제공 회고 반영 후: 총 57개 기록(제공 사건 52개 + 실제 코드 기록 5개)을 확인했습니다. 1440px·360px에서 상태/출처 필터, 상세 펼치기, 드래그·방향키 이동, 처음/최신 이동, Escape·닫기와 포커스 복귀를 확인했습니다. 모바일 창 너비는 336px이며 가로 넘침이 없었습니다. 기존 8779 서버에서도 새 정적 연표를 제공하며, 변경 없는 `--scan`은 57개를 유지했습니다. 웹 코드 검사를 통과했고 분석 API는 호출하지 않았습니다. 화면 기록은 `output/playwright/timeline-desktop.png`, `timeline-mobile.png`입니다.

아래는 최초 연표 구현 당시의 기록입니다.

2026-10-07, 기존 8779 서버를 유지하며 1440px·768px·360px에서 확인했습니다. 마우스 드래그, 모바일 터치 드래그, 방향키 이동, 처음·최신 이동, Escape·닫기, 버튼으로 포커스 복귀, 위치 기억, 화면 안으로 위치 보정이 동작했습니다. 작은 화면에서 진행상황·변경 이력 버튼을 함께 표시해도 자료 선택 버튼이 세로로 꺾이지 않는지 확인했습니다. 브라우저 오류는 없었고, 정적 화면 코드 검사도 통과했습니다. 연표 27개 항목은 실제 정적 경로에서 읽히며, 변경 없는 재검사는 항목 수를 늘리지 않았습니다. 백엔드 코드·자료·AI 분석 설정은 이번 작업에서 수정하지 않았습니다.
