# 제작 상태와 최종 검증 계획

사용자 요청(2026-10-06)에 따라 v0.7까지 제작을 마친 뒤 통합 검증했다. 테스트 63개 통과(기존 51개 + 새 통합 12개). 합성 샘플에서 실제 NVIDIA 가설/계획 생성과 Jev 점수화를 확인했다. [결과 예시](../output/integration_v07_preview.md)와 [상세 기록](../output/integration_v07_verification.json)을 보존한다.

| 구현 단계 | 제작 상태 | 검증 상태 |
|---|---|---|
| v0.1 자료 그래프 | 기존 구현 | 이전 단계에서 검증 |
| v0.2 문제별 그래프 | 기존 구현 | 이전 합성 2문항 실제 API 및 51개 테스트; 실제 시험 정확도 미평가 |
| v0.3 반복 패턴 | 작성 완료 | 문항 support/시험 분모·방향/동형 구조·상한·재실행 확인; 실제 샘플 반복 노드 4개, 반복 edge/path/subgraph 0개 |
| v0.4 가설 | 작성 완료 | 모의 연결/유보/캐시·stale 거부 확인; 실제 NVIDIA 후보 1개 생성 |
| v0.5 Jev scoring | 작성 완료 | Score 계약/잘못된 수치·분포 거부/실패 보호/캐시 확인; 실제 Jev 가설 1개·개념 1개 판단 |
| v0.6 Teacher Model | 작성 완료 | 스키마·연결·미관찰·이전 모델 비교/갱신 확인; 실제 개념 6개 중 점수 1개, 나머지 null |
| v0.7 Plan | 작성 완료 | CLI·예산·완료 상태/변경 해제·메모/이력·실패 보호 확인; 실제 NVIDIA 과제 2개 생성 |

실제 호출 합계는 NVIDIA 2회·Jev 7회다. 핵심 검증에는 Jev 4회가 필요했다. 첫 CLI 테스트의 모의 생성자 패치 위치가 잘못돼 Jev가 3회 추가 호출됐으며, 올바른 모듈 패치와 테스트 네트워크 차단으로 수정했다. 마지막 63개 테스트 실행은 모의 응답으로 진행했다. API 비용 금액은 측정하지 않았다.

범위 제한: 기존 v0.2의 합성 2문항 추출 결과를 재사용했다. 실제 교사 시험 정확도, 다른 단원 새 범위 전이, 사람의 과학 검수, 대규모 성능/비용 평가는 하지 않았다. 아래 상세 목록 전체를 각각 독립적으로 검증했다는 뜻은 아니다.
