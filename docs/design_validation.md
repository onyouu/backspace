# Black & Lime 디자인 검증 기록

2026-10-06. 기존 Python/Vanilla JS, JSON 계약과 두 입력 공간을 유지했다. 원문과 기존 모델·계획을 재분석하지 않았다. 실제 미리보기는 기존 서버를 종료하지 않고 http://127.0.0.1:8770/ 에서 제공한다.

## 자동 검사

- Python 계약·회귀 테스트 **81개 통과** (`output/design-tests.log`). 정적 제공 검사에 GSAP Core/Flip/ScrollTrigger/SplitText/DrawSVG, 로컬 폰트·라이선스와 분리된 화면 모듈을 포함했다. 허용하지 않은 vendor 파일과 경로 탈출도 거부됨을 검사했다.
- `npm run check` 통과: 5개 화면 스크립트 구문, 61개 입력에서 선택 개념 보존/최대 24개 표시/저장된 관계만 사용/단일 반복 노드에 경로를 추가하지 않음/저장된 경로 관계 유지.
- 시스템 동작 줄이기·사용자 모션 끄기·GSAP 없음에서 모션이 비활성화되는 조건 검사 통과.
- 기존 100MiB 상한, 자료 분리, 원본·최초 전사·수정 이력, 모델 해시와 계획 상태 저장 계약을 유지했다.

## 실제 브라우저 확인

360·768·1440·1920px에서 홈·지도·계획을 확인했다. 문서 전체의 가로 넘침은 없었다. 768px 접이식 메뉴는 펼친 상태에서 이동하고, 접힌 메뉴는 키보드 탐색에서 제외한다. 모바일은 이름이 있는 하단 메뉴와 근거 시트를 제공한다. 작은 지도는 자체 영역에서 좌우로 스크롤해 라벨의 글자 크기를 유지한다.

격리된 합성 저장공간 `output/design_qa`를 사용했다. 로컬 업로드 → TXT 읽기 → 원문 검토를 실행했고 긴 한국어 파일명이 줄바꿈됨을 확인했다. 별도의 합성 모델에서 개념/문항 Q1·Q2/반복 노드 전환, 미산정 중요도 `—`, 지지 2/분석 2문항, 원문 위치와 가설 대안을 확인했다. 같은 데이터로 날짜/전체 과제 전환, 완료 저장, 완료 기준, 메모 저장 및 계획 수정 필요 안내를 확인했다. 과제 완료 갱신 중 입력한 기간(9일)과 미저장 메모가 남았다. 전체 모델 연결 파이프라인은 기존 모의 응답 통합 테스트로 검증했다.

원문 검토는 확인 대기 필터를 기본으로 열었다. 필터 변경 후 수정이 유지됐고 한 블록 저장 후 다른 블록의 미저장 입력이 남았다. 최초 인식/수정 이력을 확인했다. 닫기 보호의 계속 수정/버리고 닫기를 확인했고, 저장 실패 모의 응답에서도 입력과 오류 문구를 유지했다. 데스크톱 원본/편집 2열 및 모바일 이미지/텍스트 탭, 실제 이미지 로딩(900×440), 선택 좌표 강조를 확인했다. 모바일 근거 닫기와 완료 기준 모달은 선택한 버튼으로 포커스가 돌아왔다.

빈 시험범위, 모델 없음/다음 단계, 확인 대기, 읽기 실패, 오래된 모델·계획, 미산정 점수를 합성 상태로 확인했다. 모든 GSAP vendor 요청을 의도적으로 실패시키는 격리 서버에서도 문항 지도 선택과 계획 완료 저장이 동작했다. 사용 안내의 모션 끄기/켜기를 확인했다.

Chrome 확장 파일 접근 권한이 없어 Chrome 자동 업로드는 제한됐다. 권한을 바꾸지 않고 인앱 브라우저에서 업로드와 로컬 읽기를 검증했다. 일반 사용자 파일 선택 기능을 제한하는 앱 코드 변경은 없다.
