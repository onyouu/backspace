생명과학 자료의 노트는 총 115개입니다. 나머지 안내자료의 노트 1개를 포함하면 116개입니다. 범위 완료는 채택된 텍스트를 노트로 저장했다는 의미입니다. 확인 대기 OCR 영역까지 읽었거나 모든 그림과 과학 내용이 정확하다는 뜻은 아닙니다.

마지막 실제 작업은 **부분 성공**, 미완료 단계는 **19건**입니다. 주요 기록은 원문 인용 불일치, 응답 형식 오류, 시간·답변 길이 제한, 연결 실패입니다. 완료 그래프에도 `31I`, `45577`, `Bold`, `Fol-12t` 같은 잡음이 개념으로 들어가 있습니다. 원문에 글자가 존재한다는 검사만으로 교과 개념인지 판단할 수 없다는 문제가 드러났습니다.

실제 Teacher Model은 갱신 필요 상태입니다. 분석된 시험문항은 0개이고 실제 자료 공간의 학습계획도 없습니다. 따라서 실제 자료로 Teacher Model부터 학습계획까지 모두 완료됐다고 판정할 수 없습니다. 노트의 과학적 정확성도 이번 소프트웨어 검증으로 인증하지 않았습니다.

## 테스트 중 발견해 보완한 오류

예시 화면에서 계획을 다시 만들 때, 예전 개념 지도와 현재 저장 자료가 맞지 않아 실패했습니다. 이제 예시 작업공간을 준비할 때 개념 지도를 저장된 자료에서 다시 계산합니다. 기존 자료와 계획을 지우지 않고 지도 이력도 남깁니다. 이 경우를 자동 테스트에 추가했고, 예시 복사본에서 지도를 갱신한 뒤 계획 생성이 완료되는 것도 확인했습니다.

현재 8778 서버는 수정 전 Python 코드를 불러온 상태로 실행 중입니다. 이번 서버 수정은 다음 실행부터 적용됩니다. 새 코드의 실패 처리 검증과 현재 실제 데이터의 분석 품질을 같은 것으로 보고하지 않았습니다.
